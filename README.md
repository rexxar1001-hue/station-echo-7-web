# STATION ECHO-7 — веб-квест для двух игроков

Статический сайт (HTML + CSS + vanilla JS, без сборки и бэкенда) для игры на двоих:
**Агент** работает с сайтом, **Аналитик** — только с печатным блокнотом.
Цепочка квестов 0–8 приводит к числовому коду от физического замка.

## Как запустить

Сайт нужно открывать **через локальный сервер**, а не двойным кликом по файлу
(`file://` блокирует загрузку базы SQLite и WASM).

```bash
git clone <адрес репозитория>
cd station-echo7
python3 -m http.server 8000
```

Затем открыть <http://localhost:8000/>.

### Режим доступа

В `js/config.js` есть флаг `openAccess`:

* `true` (по умолчанию) — все разделы станции открыты сразу, сайт работает как обычный;
  `dashboard.html` — главная страница со ссылками на все разделы;
* `false` — разделы открываются по мере прохождения квестов, как в исходном сценарии.

Страница дневника `diary-vorel-087.html` остаётся скрытой в обоих режимах — ссылок на неё нет.

Для квестов 1, 6 и 8 нужен интернет — библиотеки sql.js, exifr, Leaflet и Pyodide
подключаются с CDN.

### GitHub Pages

Включите Pages для ветки `main`, папка `/ (root)`. Все пути в проекте относительные,
поэтому сайт работает и в подпапке вида `https://<user>.github.io/station-echo7/`.

## Что нужно заменить перед игрой

1. **Медиа** — все файлы в `img/` и `audio/` сейчас заглушки. Список имён и требований: [ASSETS.md](ASSETS.md).
2. **Дневник** — `diary-vorel-087.html`, сейчас текст-заглушка с **временным кодом 4729**.
3. При желании — параметры игры в `js/config.js`.

## Прогресс и отладка

Прогресс хранится в `localStorage` браузера Агента (флаги `q0`…`q8`).
Сбросить игру перед новым прохождением: открыть `reset.html`.
