# Медиа-ассеты: какие файлы и под какими именами подставлять

Сейчас все файлы в `img/` и `audio/` — **заглушки**, созданные скриптом
`tools/make_placeholders.py`. Заменяйте их своими файлами, **сохраняя имена и расширения**.
Ничего в коде менять не нужно.

Пересоздавать заглушки скриптом `tools/make_placeholders.py` не нужно: он не обновлён под фото 003 (см. примечание ниже).

### EXIF, обязательный для `field_photo_003.jpg`

| Тег | Значение |
|---|---|
| GPSLatitude | 45° 53' 32.28" N |
| GPSLongitude | 13° 03' 51.12" E |

Проще всего вшить их так: положить своё фото в `img/field_photo_003.jpg` и запустить

наличием координат, а ложные координаты уводят в другие места острова.
После замены фотографий своими перевшейте метаданные:


## 2. Карта острова (квест 3) — `img/island.jpg`

Карта уже нарисована и согласована с фотоархивом: каждая точка AP стоит на том
ландшафте, который виден на её снимках (озеро с причалом, карьер, болото, ферма
и т.д.). При клике по точке открывается её фото.

* Размер полотна: **1500 × 1000** пикселей (другой размер — поправьте `IMG_W` / `IMG_H`
  в `map.html`).
* На карте нет подписей точек — точки рисует Leaflet поверх картинки.
* Все 15 точек AP-01…AP-15 заданы в `js/config.js` (`mapPoints`): `x`, `y` в пикселях
  (X слева направо, Y снизу вверх, нижний левый угол = 0,0), `place` — подпись,
  `photos` — снимки этой точки.
* Фото `field_photo_003.jpg` (снимок самого Daniel Stern, из квеста 2) показывается **только** в точке
  AP-07 — по нему игроки подтверждают верную точку в кластере AP-03 / AP-07 / AP-11. Ни в одной другой точке его
  быть не должно. Фото `field_photo_023.jpg` теперь не привязано к точкам карты (остаётся только в фотоархиве).
  Выключить снимки в точках целиком — флаг `mapPhotos: false` в `js/config.js`.

## 3. Радиоархив (квест 4) — папки `audio/AP-01/` … `audio/AP-15/`

У каждой из 15 точек карты своя папка `audio/AP-NN/` с теми же 14 файлами (имена ниже). Сейчас во всех точках, кроме AP-07,
лежат одинаковые заглушки (шум, 2 с); их можно заменять по отдельности, сохраняя имена. **Верная запись — только
`audio/AP-07/rec_142.7.wav`**; одноимённые файлы в других точках — обычный шум (спектрограмма там тоже без метки SHADOW-01).

Ниже — описание папки `audio/AP-07/`:

14 файлов, верный — `rec_142.7.wav`:

```
rec_38.6.wav   rec_47.2.wav   rec_59.4.wav   rec_71.9.wav
rec_88.3.wav   rec_96.5.wav   rec_104.8.wav  rec_117.2.wav
rec_128.0.wav  rec_142.7.wav  ← ВЕРНЫЙ      rec_166.4.wav
rec_181.3.wav  rec_205.1.wav  rec_219.6.wav
```

* Формат: WAV (PCM). Длительность 3–15 секунд.
* В `rec_142.7.wav` фраза про сектор GAMMA должна быть записана **задом наперёд**,
  чтобы кнопка Reverse на сайте её «выпрямила». То есть: запишите нормальную фразу,
  разверните её любым редактором (или командой ниже) и сохраните развёрнутую версию.

```bash
ffmpeg -i phrase.wav -af areverse audio/AP-07/rec_142.7.wav
```

* Остальные 13 файлов — шум/помехи/обрывки без смысла (в том числе в реверсе).

### Спектрограммы (картинки, не реальный анализ) — папка `img/`

| Имя файла | Что на картинке |
|---|---|
| `spectrogram_rec_142.7.png` | **ВАЖНАЯ.** Спектрограмма с вплетённой надписью `SHADOW-01` |

## 4. Видеонаблюдение (квест 7) — папка `img/`

| Имя файла | Что это |
|---|---|
| `camera_01_empty.jpg` … `camera_10_empty.jpg` | Статичные кадры 10 камер |
| `camera_04.mp4` | **ВАЖНЫЙ.** Зацикленная запись камеры GAMMA-CAM-04, на которой периодически мелькает силуэт человека. Файл нужно добавить |

Камера `GAMMA-CAM-04` показывает `camera_04.mp4` как видео без кнопок управления
(автозапуск, без звука, в цикле — выглядит как анимированная картинка), остальные девять —
свои статичные `camera_NN_empty.jpg`. Пока `camera_04.mp4` не добавлен (или браузер не может
его проиграть), сайт показывает вместо него `camera_04_empty.jpg`, поэтому ничего не ломается.
Мерцание силуэта должно быть записано в самом видео (код сайта его не имитирует).

Требования к `camera_04.mp4`: видео H.264 (yuv420p), **без звуковой дорожки**, первый и
последний кадры одинаковы (для бесшовной петли), формат 16:9. Подходящая команда для
конвертации любого исходного видео или GIF:

```bash
ffmpeg -i source.mp4 -vf "scale=640:-2" -an -c:v libx264 -profile:v main -pix_fmt yuv420p \
       -crf 26 -preset slow -movflags +faststart img/camera_04.mp4
```

Файл `camera_04_figure.jpg` сайтом больше не используется.

## 5. Громкоговорители камер (квест 7) — папка `audio/`

Каждая камера воспроизводит свой файл `audio/speaker_<имя_камеры>.wav` (строчными, дефисы → `_`):
`speaker_alpha_cam_01.wav`, `speaker_beta_cam_02.wav`, `speaker_beta_cam_03.wav`,
**`speaker_gamma_cam_04.wav`** (важный), `speaker_gamma_cam_05.wav`, `speaker_delta_cam_06.wav`,
`speaker_epsilon_cam_07.wav`, `speaker_zeta_cam_08.wav`, `speaker_eta_cam_09.wav`, `speaker_theta_cam_10.wav`.
Сейчас все десять — одна и та же заглушка (белый шум, 3 с). Прогресс засчитывается только на GAMMA-CAM-04.

Для `speaker_gamma_cam_04.wav` — короткая (5–10 с) реплика раненого Daniel Stern. Текст, который выводится на экране
рядом с аудио, задан в `cameras.html` (константа `SPEAKER_LINE`) — при изменении
записи поправьте и его.
